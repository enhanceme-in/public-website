Chapter 4: JavaScript Arrays 101Welcome to Chapter 4! So far, we've been working with variables that hold just one thing at a time.let myPet = "Sparky";
let myFavoriteNumber = 17;

That's great, but what happens when you need to store a list of things? Imagine trying to store your grocery list, a list of all your friends' names, or the top five scores in a game.let item1 = "milk";
let item2 = "eggs";
let item3 = "bread";
// ...this is getting clumsy!

This is where Arrays come in. An array is a single, special variable that can hold multiple items in a neat, ordered list.What is an Array?Think of an array like a set of numbered lockers. The entire set of lockers has one name (the variable name), but each individual locker has a number (called an index) so you can find exactly what's inside.Creating Your First ArrayCreating an array is simple. You just use square brackets [] and separate your items with commas. This is called an "array literal."// An array of strings
let fruits = ["apple", "banana", "cherry"];

// An array of numbers
let scores = [100, 85, 92, 78];

// An array with mixed types (JavaScript is flexible!)
let mixedBag = ["hello", 10, true, null];

// You can also start with an empty array
let emptyLocker = [];

For the rest of this chapter, let's use our fruits array.let fruits = ["apple", "banana", "cherry"];

The Most Important Rule: Indexes Start at 0This is the most important concept in all of array programming, so let's say it loud: Array indexes always start at zero!It might feel strange at first—we're used to counting from 1. But in programming, the first item is at position 0, the second is at position 1, and so on.Think back to our lockers. The first locker is "Locker 0," the second is "Locker 1," etc.Let's visualize our fruits array:| Item | "apple" | "banana" | "cherry" || Index | 0 | 1 | 2 |Accessing Items in an ArraySo, how do you open a locker to see what's inside? You use the array's name followed by the index in square brackets [].let fruits = ["apple", "banana", "cherry"];

// Get the _first_ item (at index 0)
console.log(fruits[0]); // Output: "apple"

// Get the _second_ item (at index 1)
console.log(fruits[1]); // Output: "banana"

// Get the _third_ item (at index 2)
console.log(fruits[2]); // Output: "cherry"

What happens if you try to access an index that doesn't exist?If you ask for an item at an index that's out of bounds, JavaScript won't crash. It will just give you the special value undefined.console.log(fruits[3]); // Output: undefined
console.log(fruits[99]); // Output: undefined

Updating Items in an ArrayWhat if you want to swap an item out of a locker? You just assign a new value to that specific index.Let's say we want to change "banana" to "blueberry". "banana" is at index 1.let fruits = ["apple", "banana", "cherry"];
console.log(fruits); // Output: ["apple", "banana", "cherry"]

// Update the item at index 1
fruits[1] = "blueberry";

console.log(fruits); // Output: ["apple", "blueberry", "cherry"]

Easy! You just targeted the "locker" and put something new inside.A Handy Property: .lengthHow can we quickly find out how many items are in our array? Every array comes with a built-in length property.It's just the array name, a dot, and the word length (no parentheses!).let fruits = ["apple", "banana", "cherry"];
console.log(fruits.length); // Output: 3

let scores = [100, 85, 92, 78];
console.log(scores.length); // Output: 4

let emptyLocker = [];
console.log(emptyLocker.length); // Output: 0

The .length and Index ConnectionThere is a vital connection between the length and the last index:The last item's index is always length - 1.Why? Because we start counting the index at 0!Our fruits array has a length of 3.The items are at indexes 0, 1, and 2.The last index is 2, which is 3 - 1.This is a super common pattern. If you want to get the last item in any array, you can do this:let fruits = ["apple", "banana", "cherry", "date", "elderberry"];

let lastIndex = fruits.length - 1; // 5 - 1 = 4
console.log(fruits[lastIndex]); // Output: "elderberry"

Adding and Removing Items (A Quick Peek)What if you want to add a new item to the end of the list? Or remove the last item? Arrays have built-in "tools" (called methods) to do this.We'll cover these in detail in the next chapter, but here are the two most common ones..push() - Add to the EndThe .push() method adds one or more items to the very end of the array.let fruits = ["apple", "banana"];
console.log(fruits); // Output: ["apple", "banana"]
console.log(fruits.length); // Output: 2

fruits.push("cherry"); // Add "cherry" to the end

console.log(fruits); // Output: ["apple", "banana", "cherry"]
console.log(fruits.length); // Output: 3

.pop() - Remove from the EndThe .pop() method removes the last item from the array and also (handily) returns the item it removed.let fruits = ["apple", "banana", "cherry"];
console.log(fruits); // Output: ["apple", "banana", "cherry"]

let removedFruit = fruits.pop(); // Remove the last item

console.log(fruits); // Output: ["apple", "banana"]
console.log(removedFruit); // Output: "cherry"
