  A gentle intro to how garbage collectors (like V8) decide what’s collectible (mark-and-sweep, generational GC, etc.).

  More real-world mistakes (accidental global leaks, keeping references in libraries, etc.).

  If you want a final appendix: how memory works in server-side JS (Node.js)—very similar but some unique features.
